# NyxCitadel Demo Playbook

## Purpose
Use this script to run the same 10-minute story every time while keeping data believable and fresh.

## Before Every Demo
1. Log in as Admin.
2. Open Admin Control Panel.
3. Click Reset Demo Data and wait for success toast.
4. Refresh browser tabs to ensure fresh dashboard counts.

## 10-Minute Sales Script
1. Mission framing (60s)
- Show Dashboard and explain one command center for compliance, risk, and emergency readiness.

2. Risk signal flow (2 min)
- Open Incidents and highlight recent sentinel/medication items.
- Open CAPs and show accountable remediation with dates and owners.

3. Workforce and readiness (2 min)
- Open Training tracker for completion and overdue insight.
- Open Drills module for scheduled/completed emergency exercises.

4. Automation proof (2 min)
- Go to Admin Panel.
- Show Automation Status card and recent run history.
- Trigger Run Alerts Now to prove live automation.

5. Executive reporting (2 min)
- Open Export Center.
- Download Board Packet (saved packet).
- Open Board PDF and highlight trend page + operational cadence.

6. Operational close (60s)
- Show Export Delivery Lists and explain external executive recipients with cadence controls.
- Reinforce that alerts, exports, and board reporting are production-ready workflows.

## Demo Recovery if Something Looks Stale
1. Run Reset Demo Data again.
2. Trigger Run Alerts Now once.
3. Re-download Board PDF.

## Optional Deep-Dive Paths
- Compliance teams: policies + calendar + reminders.
- Risk teams: incidents + RCA + CAP linkage.
- Executive teams: board PDF trends + scheduled export delivery lists.
