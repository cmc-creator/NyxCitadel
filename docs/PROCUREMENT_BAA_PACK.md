# Procurement and BAA Pack Outline

## Purpose

Use this as the buyer-facing package structure for hospital legal, security, and IT review cycles.

## Core Legal Documents

- Mutual NDA
- Master Services Agreement (MSA)
- Business Associate Agreement (BAA)
- Data Processing Addendum (if required)
- Service Level Agreement (SLA)

## BAA Schedule Recommendations

- PHI scope and permissible uses
- Administrative, physical, and technical safeguards
- Breach notification window and communication protocol
- Subcontractor/subprocessor obligations
- Return or destruction of PHI on termination

## Security and IT Attachments

- Security hardening checklist (`docs/SECURITY_HARDENING_CHECKLIST.md`)
- Architecture and data residency statement
- Backup/restore and disaster recovery summary
- Access control model and least-privilege approach
- Audit logging capabilities and retention defaults

## Implementation Plan for New Hospital

1. Tenant setup and admin onboarding
2. Data migration/import strategy
3. Staff role mapping and permissions
4. Pilot period success metrics
5. Production go-live checklist

## Pilot Success Metrics (Buyer Language)

- Compliance completion rate change
- CAP overdue rate reduction
- Training completion lift
- Automation reliability and operational time saved
- Executive reporting turnaround reduction

## Contracting Readiness Checklist

- Finalize pricing, pilot scope, and term length
- Confirm security questionnaire responses
- Confirm cyber liability insurance documentation
- Validate BAA execution workflow and signatories
- Approve go-live criteria and support escalation path
